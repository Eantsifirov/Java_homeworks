Запуск:

Требуется Java 17+ и Maven.

Запуск тестов:

mvn test

Эксперимент производительности запускается через метод main() класса CollectionPerformanceExperiment.

Расположение заданий

Задание 1: CustomList.java, CustomArrayList.java и CustomArrayListTest.

Задание 2: CollectionPerformanceExperiment.java.

Выводы:

По таким операциям, как добавление в конец и удаление из конца обе структуры показывают схожие результаты, так как выполняют схожие действия (дописывают элемент или создают ноду и прикрепляют в конец).
По вставке в середину результат различается примерно в 20 раз, причём linkedlist отстаёт. В то время, как ArrayList просто добавляет элемент и сдвигает половину вправо (здесь на эффективность работает
локальность данных в массиве), LinkedList вынужден постоянно проходить по ссылкам (на объекты, потенциально разбросанные в памяти компьютера) половину массива - это действие заметно более затратное.

В случае с последовательным получением всех элементов на разнице в 80 раз сказывается ассимптотика: ArrayList делает n доступов за O(n), а LinkedList дополнительно проходит по связям, отсюда O(n^2).

Наконец, на таких операциях как вставка в начало и удаление из начала, LinkedList заметно (в 5-7 раз) выигрывает. Это связано с тем, что ему требуется просто добавить или удалить первую ноду, в то время как
ArrayList сдвигает вперёд все свои элементы.
